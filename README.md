# Lab8
Інструкція зі збирання та запуску
Для збирання та запуску проєкту необхідні: операційна система Windows 10/11, середовище Visual Studio 2022 з компонентом Desktop development with C++, CMake версії не нижче 3.21 та пакетний менеджер vcpkg.
Проєкт використовує режим manifest vcpkg. Залежності sqlite3 та sqlite-orm визначені у файлі vcpkg.json і встановлюються автоматично під час конфігурації.
Рекомендований спосіб збирання — через Visual Studio. Необхідно відкрити папку проєкту, вибрати preset x64-debug, дочекатися завершення конфігурації CMake, виконати збирання та запустити програму.
Альтернативно проєкт можна зібрати з командного рядка: спочатку виконати конфігурацію за допомогою cmake --preset x64-debug, потім збирання командою cmake --build out/build/x64-debug. Запуск здійснюється виконанням файлу CallCenterORM.exe з каталогу збірки.
Після запуску програма послідовно виконує всі демонстраційні сценарії лабораторної роботи: порівняння SQLite C API та ORM, роботу зі зв’язком 1:N, CRUD-операції через Repository, запити з фільтрацією, сортуванням, агрегацією та JOIN, а також транзакції з фіксацією та відкатом змін. Програма завершується з кодом 0.
Файли баз даних створюються та очищаються автоматично. Перевірка зовнішніх ключів увімкнена. Проєкт реалізовано з використанням стандарту C++20.
